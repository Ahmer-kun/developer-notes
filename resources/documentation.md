# Documentation

Primary sources I check when verifying things. Prefer these over blog posts.

## Web and JavaScript

- MDN Web Docs: https://developer.mozilla.org
- ECMAScript specification: https://tc39.es/ecma262/
- Node.js documentation: https://nodejs.org/docs/latest/api/
- WHATWG Fetch Standard: https://fetch.spec.whatwg.org

## Protocols (RFCs)

- RFC 9110: HTTP Semantics
- RFC 6265: HTTP State Management (cookies)
- RFC 7519: JSON Web Token
- RFC 8725: JWT Best Current Practices
- RFC 1034 / 1035: DNS
- RFC 9293: TCP
- RFC 768: UDP

RFCs can be found at https://www.rfc-editor.org.

## Tools

- Pro Git (free book): https://git-scm.com/book
- Git reference: https://git-scm.com/docs
- PostgreSQL documentation: https://www.postgresql.org/docs/
- MySQL reference manual: https://dev.mysql.com/doc/

## Security

- OWASP Cheat Sheet Series: https://cheatsheetseries.owasp.org
- OWASP Top 10: https://owasp.org/www-project-top-ten/

## Local

- `man <command>` and `<command> --help` for anything installed on the machine.
